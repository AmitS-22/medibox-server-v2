# 💊 MediBox

A modern **Medicine Management Application** built with **React Native (Expo)** and **Node.js (Express.js)**. MediBox helps users manage medicines, organize daily schedules, and keep track of medications through a clean and intuitive interface.

---

## ✨ Features

- 🔐 User Authentication (Login & Register)
- 💊 Add New Medicines
- 📝 Update & Delete Medicines
- 📋 View Medicine List
- ⏰ Medicine Reminder Support
- 📱 Responsive & Modern UI
- 🌐 REST API Integration
- 📦 Backend using Express.js
- 🗄️ MongoDB Database Integration

---

## 🛠️ Tech Stack

### Frontend
- React Native (Expo)
- JavaScript (ES6+)
- React Navigation
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/AmitS-22/medibox-server-v2.git
```

### 2. Backend Setup

```bash
cd Backend
npm install
npm start
```

### 3. Mobile App Setup

```bash
cd mobile-app
npm install
npx expo start
```
